# loading screens

green background, large bold black text

intended to provide visual context to viewers of the asr_server stream. 

loading screens should:
- have a green background(same as racing view's grass) with large bold black text
- should be shown for a minimum of 3 seconds before transitioning to the race view
- have a fade away transition to the race view
- shown over all other UI elements
- display before each qualifying race
- display before each main series race
- include information about the type of race and the race number on the loading screen
